# Evaluación heurística de UX

Usala para revisar una pantalla, un flujo o un prototipo y encontrar problemas de usabilidad (sirve también con capturas del navegador).

## Las 10 heurísticas (Nielsen)
1. Visibilidad del estado del sistema (feedback, cargas, progreso).
2. Correspondencia con el mundo real (el lenguaje del usuario).
3. Control y libertad (deshacer, cancelar, salir).
4. Consistencia y estándares.
5. Prevención de errores (confirmaciones, validación previa).
6. Reconocer antes que recordar (opciones visibles).
7. Flexibilidad y eficiencia (atajos para expertos).
8. Diseño estético y minimalista.
9. Ayudar a reconocer, diagnosticar y recuperarse de errores (mensajes claros con la solución).
10. Ayuda y documentación.

## Severidad
0 no es problema · 1 cosmético · 2 menor · 3 mayor (prioridad alta) · 4 catástrofe (bloquea la tarea).

## Entregable
Tabla: pantalla o elemento, heurística, problema observado, severidad y recomendación concreta. Cerrar con las 3 mejoras de mayor impacto.
Complementar con accesibilidad (skill accesibilidad) y, si hay usuarios reales, proponer una prueba de usabilidad con 5 participantes y tareas concretas.

Fuente: Jakob Nielsen, *10 Usability Heuristics for User Interface Design* (Nielsen Norman Group).
